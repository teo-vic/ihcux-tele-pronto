# Análise de Acessibilidade

O aplicativo foi projetado pensando em usuários idosos ou pessoas em situação de mal-estar físico. Para isso, utilizamos:

- Botões grandes e com bastante espaço entre eles, facilitando o toque mesmo com dedos trêmulos.
- Textos com tamanho ampliado e alto contraste para auxiliar usuários com visão turva.
- Interface limpa e minimalista, reduzindo distrações e carga cognitiva.
- Ícones simples e acompanhados de texto para facilitar a identificação das funções.
- Botão de emergência sempre visível em telas importantes.
- Fluxo direto para consulta, evitando excesso de etapas.

---

# Fluxo Crítico

Fluxo para iniciar uma consulta de urgência:

1. Usuário acessa a tela inicial.
2. Seleciona o botão “Consulta Agora”.
3. Realiza a triagem rápida informando sintomas.
4. O sistema direciona para a sala de espera virtual.
5. O usuário aguarda o médico entrar na chamada.
6. A consulta por vídeo é iniciada.

O fluxo foi pensado para exigir poucos cliques e reduzir dúvidas durante o uso.

---

# Prevenção de Erros

Para evitar que o usuário encerre a consulta por acidente, foram aplicadas as seguintes soluções:

- Botão “Encerrar” destacado e separado dos outros controles.
- Confirmação antes de sair da chamada.
- Espaçamento entre os botões de câmera, microfone e encerrar.
- Feedback visual ao clicar em ações importantes.
- Avisos de conexão instável antes do encerramento automático da chamada.

# Desafio Extra

## Fluxo de Dependente

O aplicativo possui troca rápida de perfil através da área “Perfis”. O responsável pode alternar entre seu perfil e o perfil do filho antes de iniciar a consulta infantil.

---

## Modo Baixa Conexão

Quando a internet fica instável, o aplicativo exibe um aviso informando que o vídeo será desativado temporariamente para priorizar o áudio da consulta.

Isso garante continuidade no atendimento mesmo em conexões ruins.
